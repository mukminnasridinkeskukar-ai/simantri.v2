Aplikasi gagal dimuat

Terjadi kesalahan saat memuat berkas JavaScript. Ini biasanya terjadi karena:

  • Anda membuka file index.html langsung dari folder (protokol file://) — aplikasi harus diakses via web server
  • Anda meng-upload source code ke GitHub Pages tanpa melalui proses npm run build terlebih dahulu
  • Konfigurasi base path di vite.config.js tidak sesuai dengan URL deployment

Solusi:

  • Pastikan GitHub Pages menggunakan Source: GitHub Actions (bukan Deploy from branch)
  • Pastikan workflow .github/workflows/deploy.yml berhasil dijalankan (cek tab Actions)
  • Untuk testing lokal, jalankan npm run dev jangan buka file langsung
Klik tombol di bawah untuk melihat detail teknis error.
